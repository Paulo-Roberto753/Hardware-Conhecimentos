## 17. Resumo: o que você precisa memorizar?

| Termo | Significado |
|---|---|
| PCB | Placa de circuito impresso. |
| Chipset | Gerencia e disponibiliza recursos de comunicação. |
| VRM | Regula a alimentação elétrica dos componentes. |
| Socket | Encaixe físico do processador. |
| BIOS/UEFI | Firmware responsável pela inicialização e configuração. |
| POST | Verificação inicial do hardware. |
| PCIe | Interface para conexão de componentes. |
| M.2 | Formato físico para SSDs e módulos. |
| SATA | Interface para armazenamento. |
| ATX | Formato físico de placa-mãe. |
| Header | Conector interno da placa. |
| Revision | Versão física do projeto da placa. |
| QVL | Lista de componentes testados pelo fabricante. |
