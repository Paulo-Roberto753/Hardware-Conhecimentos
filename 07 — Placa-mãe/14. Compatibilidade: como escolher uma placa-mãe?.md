## 14. Compatibilidade: como escolher uma placa-mãe?

A compatibilidade é um dos pontos mais importantes na montagem e manutenção de computadores.

Uma placa-mãe precisa ser compatível com o processador, memória, armazenamento, gabinete e demais componentes.

**Principais verificações:**

| Componente | O que verificar |
|---|---|
| Processador | Socket, geração e lista de CPUs suportadas. |
| BIOS | Versão mínima necessária para o processador. |
| Memória RAM | DDR4/DDR5, capacidade e frequências suportadas. |
| Placa de vídeo | Slot PCIe e espaço físico no gabinete. |
| SSD NVMe | Protocolo, geração, pistas e formato M.2. |
| HD/SSD SATA | Portas SATA disponíveis. |
| Fonte | Conectores de alimentação necessários. |
| Gabinete | Formato físico e espaço disponível. |
| Cooler | Compatibilidade com socket e espaço para instalação. |

### Exemplo prático

Imagine uma placa-mãe com as seguintes especificações:

**Placa-mãe — Exemplo de ficha técnica**

| Característica | Especificação |
|---|---|
| Socket | AM4 |
| Chipset | B550 |
| Memória | DDR4 |
| Slots RAM | 4 |
| PCIe principal | PCIe 4.0 |
| M.2 | 2 slots |
| SATA | 4 portas |
| Formato | Micro-ATX |

Antes de instalar um processador Ryzen nessa placa, é necessário consultar a lista oficial de CPUs suportadas e verificar a versão de BIOS exigida.

**Regra prática:** nunca compre ou instale um componente considerando apenas o nome do socket ou do chipset. Consulte o manual e a lista oficial de compatibilidade.
