## 14. Ferramentas para análise e testes

| Ferramenta | Finalidade |
|---|---|
| CrystalDiskInfo | Consultar SMART e saúde do HD. |
| CrystalDiskMark | Medir velocidades de leitura e gravação. |
| SeaTools | Diagnóstico de unidades Seagate. |
| WD Dashboard | Informações e diagnóstico de unidades Western Digital compatíveis. |
| HWiNFO | Consultar informações e temperatura. |
| CHKDSK | Verificar e corrigir problemas no sistema de arquivos. |

**Diferença importante:**

- CrystalDiskInfo: monitora os indicadores SMART.
- CrystalDiskMark: mede o desempenho.
- CHKDSK: verifica o sistema de arquivos e, com parâmetros específicos, pode verificar setores. Não é uma ferramenta de diagnóstico mecânico do HD.
