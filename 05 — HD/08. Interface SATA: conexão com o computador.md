## 08. Interface SATA: conexão com o computador

SATA (*Serial Advanced Technology Attachment*) é uma interface utilizada para conectar HDs à placa-mãe.

[pcinside.info](https://www.pcinside.info/nl/zelfbouw/installatie-van-een-harde-schijf-sata-en-ide/?utm_source=chatgpt.com)

O HD SATA utiliza dois conectores:

- **SATA Data:** responsável pela transferência de dados.
- **SATA Power:** responsável pela alimentação elétrica.

| Versão | Velocidade teórica |
|---|---|
| SATA I | 1,5 Gb/s |
| SATA II | 3 Gb/s |
| SATA III | 6 Gb/s |

**Importante:** um HD SATA III pode funcionar em uma conexão SATA II, mas ficará limitado à velocidade da interface mais lenta.

Também existem HDs com interface SAS, bastante utilizados em servidores e ambientes corporativos.
