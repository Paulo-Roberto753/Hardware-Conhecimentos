## 07. Setores: organização dos dados

Os setores são unidades utilizadas para organizar e armazenar informações na superfície magnética do HD.

Os dados são distribuídos em regiões que podem ser acessadas individualmente.

**Principais conceitos:**

| Termo | Significado |
|---|---|
| Trilhas (Tracks) | Caminhos circulares onde os dados são organizados. |
| Setores (Sectors) | Divisões das trilhas utilizadas para armazenar dados. |
| Cilindros (Cylinders) | Conjunto de trilhas na mesma posição radial em diferentes pratos. |
| LBA | Método de endereçamento lógico dos setores. |

**Tamanhos de setor:**

- 512 bytes: tamanho tradicional.
- 4096 bytes (4 KB): formato conhecido como Advanced Format.

Alguns HDs utilizam setores físicos de 4 KB e apresentam setores lógicos de 512 bytes. Esse formato é chamado de 512e.

Outros utilizam setores lógicos e físicos de 4 KB, conhecidos como 4Kn.
