## 19. Resumo: o que você precisa memorizar?

| Termo | Significado |
|---|---|
| Platter | Prato magnético onde os dados são armazenados. |
| Read/Write Head | Cabeça de leitura e gravação. |
| Actuator Arm | Braço que movimenta as cabeças. |
| Spindle | Motor responsável pela rotação dos pratos. |
| RPM | Rotações por minuto. |
| Cache | Memória temporária auxiliar. |
| Sector | Unidade de organização dos dados. |
| Track | Trilha magnética. |
| LBA | Endereçamento lógico dos setores. |
| SMART | Monitoramento da condição do HD. |
| Bad Block | Setor defeituoso ou problemático. |
| Reallocated Sector | Setor substituído por um setor de reserva. |
| Pending Sector | Setor aguardando nova avaliação. |
