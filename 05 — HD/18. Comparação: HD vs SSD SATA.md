Na etiqueta do HD, podemos encontrar:

- Fabricante.
- Modelo.
- Número de série.
- Capacidade.
- Interface.
- Tensão de alimentação.
- Código de identificação.

**Exemplo ilustrativo:**

| Característica | Especificação |
|---|---|
| Modelo | WD Blue |
| Capacidade | 1 TB |
| Formato | 3,5 polegadas |
| Interface | SATA III |
| Rotação | 7.200 RPM |
| Cache | 64 MB |

Sempre consulte o modelo exato para confirmar as especificações. A linha comercial, sozinha, não garante que todas as unidades tenham as mesmas características.
