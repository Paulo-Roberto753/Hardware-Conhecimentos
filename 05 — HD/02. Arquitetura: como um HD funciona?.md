## 02. Arquitetura: como um HD funciona?

Um HD é formado por componentes mecânicos, magnéticos e eletrônicos que trabalham juntos para armazenar e recuperar informações.

| Componente | Função |
|---|---|
| Pratos magnéticos | Armazenam os dados. |
| Cabeças de leitura e gravação | Leem e gravam informações nos pratos. |
| Braço atuador | Movimenta as cabeças até a região desejada. |
| Motor do spindle | Gira os pratos magnéticos. |
| Controladora PCB | Gerencia o funcionamento eletrônico do HD. |
| Cache | Armazena temporariamente informações para auxiliar nas operações. |
| Firmware | Controla as operações internas do dispositivo. |
