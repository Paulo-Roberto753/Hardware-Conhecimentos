## 10. SMART: monitoramento da saúde do HD

SMART (*Self-Monitoring, Analysis and Reporting Technology*) é uma tecnologia que permite acompanhar informações internas do HD.

Ela ajuda a identificar sinais de desgaste, erros de leitura, problemas mecânicos e possíveis falhas.

**Principais indicadores:**

| Indicador | O que informa |
|---|---|
| Health Status | Condição geral apresentada pelo software. |
| Temperature | Temperatura de funcionamento. |
| Power On Hours | Quantidade de horas ligado. |
| Power Cycle Count | Quantidade de vezes que foi ligado. |
| Reallocated Sector Count | Quantidade de setores realocados. |
| Current Pending Sector Count | Setores instáveis aguardando nova avaliação. |
| Uncorrectable Sector Count | Erros que não puderam ser corrigidos. |
| Spin Retry Count | Tentativas adicionais para iniciar a rotação, quando suportado. |

**Ferramentas para consultar SMART:**

- CrystalDiskInfo.
- SeaTools (Seagate).
- Western Digital Dashboard.
- HWiNFO.

A interpretação dos atributos pode variar conforme o fabricante. Nem todo valor bruto apresentado pelo software deve ser interpretado diretamente como uma quantidade simples.
