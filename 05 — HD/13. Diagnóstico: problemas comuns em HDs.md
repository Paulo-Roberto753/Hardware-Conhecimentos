## 13. Diagnóstico: problemas comuns em HDs

| Sintoma | Possível causa |
|---|---|
| HD não reconhecido | Cabo, alimentação, porta SATA ou falha eletrônica. |
| Lentidão excessiva | Setores problemáticos, fragmentação ou falha mecânica. |
| Estalos repetitivos | Possível problema nas cabeças ou mecanismo interno. |
| Ruído anormal | Problema mecânico. |
| Travamentos | Erros de leitura ou falhas no dispositivo. |
| Arquivos corrompidos | Problemas de leitura, gravação ou sistema de arquivos. |
| HD desaparecendo | Falha de conexão, alimentação ou defeito interno. |

**Procedimento básico de diagnóstico:**

1. Verificar se o HD aparece na BIOS/UEFI.
2. Conferir os cabos SATA de dados e alimentação.
3. Testar outra porta SATA.
4. Consultar a saúde pelo CrystalDiskInfo.
5. Verificar os atributos SMART.
6. Realizar testes com a ferramenta oficial do fabricante, se não houver sinais de falha grave.

**Atenção: HD com estalos ou falha física**

Se o HD apresentar estalos repetitivos, ruídos mecânicos incomuns ou desaparecer durante o uso, evite insistir em testes, formatação ou CHKDSK. Desligue o dispositivo e priorize a recuperação dos dados importantes com assistência especializada.
