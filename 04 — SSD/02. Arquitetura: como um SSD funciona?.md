02. Arquitetura: como um SSD funciona?

Um SSD SATA é composto por diferentes elementos que trabalham juntos para armazenar e acessar informações.

| Componente | Função |
|---|---|
| Memória NAND | Armazena os dados. |
| Controladora | Gerencia a comunicação e o funcionamento do SSD. |
| DRAM Cache | Armazena temporariamente informações para acelerar determinadas operações, quando presente. |
| Firmware | Software interno responsável pelo gerenciamento do dispositivo. |
| Interface SATA | Permite a comunicação entre o SSD e o computador. |
| Conector SATA | Realiza a conexão de dados e alimentação. |
