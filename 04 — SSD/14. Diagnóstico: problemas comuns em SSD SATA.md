## 14. Diagnóstico: problemas comuns em SSD SATA

| Problema | Possível causa |
|---|---|
| SSD não reconhecido | Cabo SATA, alimentação, porta ou falha no dispositivo. |
| Lentidão | Pouco espaço livre, desgaste, problemas de conexão ou carga de trabalho. |
| Travamentos | Erros de leitura, firmware ou falha no SSD. |
| Temperatura elevada | Ventilação inadequada ou problema no dispositivo. |
| Erros de inicialização | Sistema operacional corrompido ou falha de armazenamento. |
| Saúde em alerta | Desgaste ou indicadores SMART problemáticos. |

**Procedimento básico de diagnóstico:**

1. Verificar se o SSD aparece na BIOS/UEFI.
2. Conferir os cabos SATA de dados e alimentação.
3. Testar outra porta SATA da placa-mãe.
4. Verificar a saúde do SSD pelo CrystalDiskInfo.
5. Consultar os dados SMART e os registros de erros.
6. Realizar backup antes de executar testes mais intensos, caso haja suspeita de falha.

**Atenção:** se o SSD apresentar erros críticos ou desaparecer intermitentemente, priorize a cópia dos dados importantes. Não comece por testes de estresse ou formatação.
