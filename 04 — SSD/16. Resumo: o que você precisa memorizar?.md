## 16. Resumo: o que você precisa memorizar?

| Termo | Significado |
|---|---|
| NAND | Memória responsável por armazenar os dados. |
| Controladora | Gerencia as operações internas do SSD. |
| DRAM Cache | Memória temporária auxiliar. |
| SATA | Interface de comunicação. |
| Leitura | Acesso aos dados armazenados. |
| Gravação | Armazenamento de novos dados. |
| TBW | Resistência de gravação especificada. |
| MTBF | Indicador estatístico de confiabilidade. |
| SMART | Monitoramento das condições do dispositivo. |
| RMA | Processo de garantia e análise do produto. |
