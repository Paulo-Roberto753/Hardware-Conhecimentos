## 10. Painel frontal e conexões

A parte frontal ou superior do gabinete pode oferecer conexões para facilitar o acesso aos periféricos.

| Conexão | Função |
| --- | --- |
| USB-A | Conexão de periféricos USB |
| USB-C | Conexão USB com conector reversível |
| P2 3,5 mm | Áudio e microfone, conforme o projeto |
| Power Button | Liga o computador |
| Reset Button | Reinicia o computador, quando disponível |
| Power LED | Indica o estado de alimentação |
| HDD LED | Indica atividade de armazenamento, quando conectado |

### Conexão com a placa-mãe

Os conectores do painel frontal são ligados aos headers correspondentes da placa-mãe.

Exemplos:

- F_PANEL;
- USB 2.0;
- USB 3.x;
- USB-C Front Panel;
- HD_AUDIO.

**Atenção:** nem toda placa-mãe possui todos os headers necessários para aproveitar as conexões do gabinete.
