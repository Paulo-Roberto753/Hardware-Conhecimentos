## 2. Arquitetura gráfica

A arquitetura gráfica representa a organização interna da GPU e a maneira como ela executa operações.

Diferentemente de uma CPU, que possui núcleos mais complexos e voltados a diferentes tipos de tarefas, uma GPU possui muitas unidades de processamento projetadas para executar operações em paralelo.

### Principais elementos:

| Elemento | Função |
|---|---|
| Shader Cores | Executam operações gráficas e cálculos paralelos |
| CUDA Cores | Unidades de processamento das GPUs NVIDIA |
| Stream Processors | Unidades de processamento das GPUs AMD |
| TMU | Unidades de mapeamento de textura |
| ROP | Unidades de operações finais de pixels |
| RT Cores | Aceleram Ray Tracing nas GPUs NVIDIA compatíveis |
| Tensor Cores | Aceleram operações de IA nas GPUs NVIDIA compatíveis |
| Cache | Armazena dados frequentemente utilizados |

**Na prática:** a arquitetura influencia o desempenho, a eficiência energética e os recursos disponíveis na placa de vídeo
