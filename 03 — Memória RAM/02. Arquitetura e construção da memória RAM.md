## 02. Arquitetura e construção da memória RAM

A memória RAM é formada por circuitos eletrônicos responsáveis por armazenar temporariamente informações.

Principais componentes:

| Componente | Função |
|---|---|
| DRAM Chips | Armazenam os dados temporários |
| PCB | Placa de circuito onde os componentes são instalados |
| Memory Controller | Controla as operações de memória |
| PMIC | Gerencia a alimentação elétrica em módulos DDR5 |
| SPD | Armazena informações de identificação e configuração |
| Dissipador | Ajuda a dissipar calor em determinados módulos |

**DRAM (Dynamic Random Access Memory):**

É a tecnologia utilizada na memória RAM convencional dos computadores.

Cada célula de memória DRAM utiliza um transistor e um capacitor para armazenar um bit de informação. Como a carga do capacitor diminui com o tempo, os dados precisam ser atualizados periodicamente por meio de um processo chamado refresh.

**SRAM (Static Random Access Memory):**

É uma memória mais rápida e utilizada principalmente em estruturas de cache dos processadores. Diferentemente da DRAM, não necessita do mesmo processo periódico de refresh.

Para memorizar:
- DRAM: utilizada como memória principal.
- SRAM: utilizada principalmente em memórias cache.
