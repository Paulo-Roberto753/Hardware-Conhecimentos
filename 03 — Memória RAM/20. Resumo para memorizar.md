## 20. Resumo para memorizar

| Termo | Significado |
|---|---|
| RAM | Memória temporária |
| DRAM | Memória dinâmica |
| SRAM | Memória estática |
| DDR | Double Data Rate |
| DIMM | Formato de módulo para desktop |
| SO-DIMM | Formato compacto para notebook |
| MT/s | Milhões de transferências por segundo |
| CL | Latência CAS |
| Timings | Tempos de operação da memória |
| Dual Channel | Dois canais de memória |
| XMP | Perfil de memória da Intel |
| EXPO | Perfil de memória da AMD |
| ECC | Correção de erros |
| Rank | Organização interna dos chips |
| SPD | Informações de identificação e configuração |
| QVL | Lista de memórias testadas pelo fabricante |
| PMIC | Gerenciamento de alimentação |
| RMA | Processo de atendimento em garantia |
