## 16. Testes de memória RAM e diagnóstico

Os testes de memória servem para identificar erros, instabilidade e possíveis falhas nos módulos.

Principais ferramentas:

**MemTest86**

Testa a memória RAM por meio de inicialização externa, geralmente via pendrive.

Site oficial

**Diagnóstico de Memória do Windows**

Ferramenta nativa para verificar problemas na memória.

Execute `mdsched.exe` pelo Windows.

**TestMem5**

Ferramenta para testar estabilidade de memória no Windows.

Projeto e informações

**CPU-Z**

Identifica informações do módulo, frequência, timings e perfis SPD.

Site oficial

Sintomas comuns de problemas na RAM:

| Sintoma | Possíveis causas |
|---|---|
| Tela azul (BSOD) | Memória instável ou outros componentes |
| Reinicializações | RAM, fonte ou placa-mãe |
| Travamentos | Erros de memória ou instabilidade |
| Falha na inicialização | Módulo mal encaixado ou incompatível |
| Bipes ao ligar | Possível falha de memória, conforme BIOS |
| Erros em testes | Módulo, controlador, configuração ou placa-mãe |

Procedimento básico de diagnóstico:
1. Desligar o computador e desconectar a alimentação.
2. Verificar encaixe e estado físico dos módulos.
3. Conferir se a placa-mãe reconhece toda a capacidade.
4. Consultar a frequência configurada.
5. Desativar XMP/EXPO temporariamente, se houver instabilidade.
6. Testar os módulos individualmente.
7. Utilizar uma ferramenta de diagnóstico.
8. Registrar os resultados.

Dica de suporte técnico: se o computador apresenta falhas com dois módulos, teste cada módulo separadamente e, quando necessário, em slots diferentes. Isso ajuda a diferenciar defeito de memória de problema no slot ou controlador.
