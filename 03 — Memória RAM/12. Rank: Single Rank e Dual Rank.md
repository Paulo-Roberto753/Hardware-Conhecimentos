## 12. Rank: Single Rank e Dual Rank

Rank representa um conjunto de chips de memória que funciona como uma unidade de largura de dados para o controlador de memória.

Principais classificações:

| Classificação | Significado |
|---|---|
| Single Rank (1R) | Um rank |
| Dual Rank (2R) | Dois ranks |
| Quad Rank (4R) | Quatro ranks |

Como identificar?

Alguns fabricantes informam essa característica na etiqueta ou ficha técnica do módulo.

Exemplo:
- 1Rx8: um rank, com organização dos chips x8.
- 2Rx8: dois ranks, com organização dos chips x8.

Importante: Dual Rank não é a mesma coisa que Dual Channel.
- Rank: organização interna do módulo.
- Channel: canal de comunicação entre memória e controlador.
