## 01. Conceito: o que é memória RAM?

RAM (Random Access Memory) é a memória temporária utilizada pelo computador para armazenar dados e instruções que estão sendo utilizados pelo processador.

Sua principal função é permitir acesso rápido às informações necessárias para executar programas, jogos e o sistema operacional.

Principais funções:
- Armazenar temporariamente dados dos programas em execução.
- Fornecer informações ao processador.
- Permitir a execução de múltiplas tarefas.
- Reduzir a necessidade de acessar o SSD ou HD constantemente.

Características importantes:
- É uma memória volátil: perde os dados quando o computador é desligado.
- Possui acesso muito mais rápido que SSDs e HDs.
- Sua capacidade é medida em GB.
- Sua velocidade de transferência é expressa em MT/s.

Para memorizar: RAM é a memória de trabalho do computador. SSD e HD armazenam os arquivos permanentemente; RAM mantém os dados necessários durante a utilização.
