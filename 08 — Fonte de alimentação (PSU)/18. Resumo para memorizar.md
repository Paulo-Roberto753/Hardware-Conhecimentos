## 18. Resumo para memorizar

| Conceito | Significado |
| --- | --- |
| PSU | Fonte de alimentação |
| AC | Corrente alternada |
| DC | Corrente contínua |
| W | Potência |
| V | Tensão |
| A | Corrente |
| PFC | Correção do fator de potência |
| 80 PLUS | Certificação de eficiência energética |
| OVP | Proteção contra sobretensão |
| UVP | Proteção contra subtensão |
| OPP | Proteção contra excesso de potência |
| OCP | Proteção contra sobrecorrente |
| SCP | Proteção contra curto-circuito |
| OTP | Proteção contra temperatura excessiva |
| ATX 24 pinos | Alimentação principal da placa-mãe |
| EPS 4+4 | Alimentação do processador |
| PCIe 6+2 | Alimentação de placas de vídeo |
| 12V-2x6 | Conector de alta potência para GPUs compatíveis |
| SATA Power | Alimentação de dispositivos SATA |
| Modular | Cabos removíveis |

### O que você precisa saber na prática?

1. Identificar a potência real e os limites de saída da fonte.
2. Entender a diferença entre tensão, corrente e potência.
3. Reconhecer os conectores ATX, EPS, PCIe e SATA.
4. Entender o funcionamento das linhas de tensão.
5. Diferenciar eficiência energética de qualidade elétrica.
6. Identificar as principais proteções.
7. Verificar a compatibilidade da fonte com CPU e GPU.
8. Diagnosticar possíveis falhas de alimentação com segurança.
