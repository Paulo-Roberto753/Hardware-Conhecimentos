## 03. Protocolo NVMe: como funciona?

NVMe é um protocolo desenvolvido especificamente para dispositivos de armazenamento baseados em memória não volátil, principalmente SSDs.

Ele foi projetado para reduzir limitações presentes em protocolos mais antigos, como o AHCI, utilizado em dispositivos SATA.

**Principais características:**

- Suporte a múltiplas filas de comandos.
- Processamento de muitas solicitações simultâneas.
- Menor latência.
- Melhor aproveitamento de processadores multicore.
- Comunicação eficiente com dispositivos PCIe.

**Comparação entre protocolos:**

| Característica | AHCI | NVMe |
|---|---|---|
| Aplicação comum | SATA | PCIe |
| Tecnologia | Desenvolvida para armazenamento SATA | Desenvolvida para armazenamento não volátil |
| Filas de comandos | 1 | Até 65.535 filas de I/O |
| Comandos por fila | Até 32 | Até 65.536 |
| Latência | Geralmente maior | Geralmente menor |

**Atenção:** esses limites são características do protocolo, não significam que todo SSD NVMe utilize a capacidade máxima de filas e comandos.
