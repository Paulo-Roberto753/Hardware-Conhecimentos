## 04. PCIe: interface de comunicação

PCIe (*Peripheral Component Interconnect Express*) é uma interface utilizada para conectar componentes de alta velocidade à placa-mãe.

Além dos SSDs NVMe, também é utilizada por:

- Placas de vídeo.
- Placas de rede.
- Placas de captura.
- Controladoras de armazenamento.

[gigabyte.com](https://www.gigabyte.com)

O PCIe permite que os dispositivos transfiram dados utilizando pistas de comunicação, conhecidas como lanes.

**Exemplo:** um SSD NVMe PCIe 4.0 x4 utiliza quatro pistas PCIe para realizar a comunicação com o computador.
