## 01. Conceito: o que é um SSD NVMe?

NVMe (*Non-Volatile Memory Express*) é um protocolo desenvolvido para permitir que dispositivos de armazenamento SSD utilizem a interface PCIe para se comunicar com o computador.

Diferentemente dos SSDs SATA, que utilizam o protocolo AHCI, os SSDs NVMe foram desenvolvidos para aproveitar melhor a velocidade e a capacidade de processamento das memórias flash.

**Principais vantagens:**

- Velocidades de leitura e gravação superiores às dos SSDs SATA.
- Menor latência de comunicação.
- Suporte a múltiplas filas de comandos.
- Melhor aproveitamento de processadores com múltiplos núcleos.
- Maior capacidade de processamento de operações simultâneas.

**Importante:** NVMe e PCIe não são a mesma coisa.

- NVMe: protocolo de comunicação.
- PCIe: interface de comunicação utilizada para transferir os dados.
