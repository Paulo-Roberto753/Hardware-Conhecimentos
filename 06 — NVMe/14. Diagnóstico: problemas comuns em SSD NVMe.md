## 13. Identificação: como reconhecer um SSD NVMe?

[bdistrict.co.uk](https://bdistrict.co.uk)

Na etiqueta ou ficha técnica, procure:

- Fabricante.
- Modelo.
- Capacidade.
- Interface PCIe.
- Geração PCIe.
- Quantidade de pistas.
- Formato físico.
- Velocidade de leitura.
- Velocidade de gravação.

**Exemplo de identificação:**

| Característica | Especificação |
|---|---|
| Modelo | SSD NVMe Gen4 |
| Capacidade | 1 TB |
| Formato | M.2 2280 |
| Interface | PCIe 4.0 x4 |
| Protocolo | NVMe |
| Leitura | Até 7.000 MB/s |
| Gravação | Até 5.000 MB/s |

Valores ilustrativos, não vinculados a um modelo específico.
