## 14. Diagnóstico: problemas comuns em SSD NVMe

| Problema | Possível causa |
|---|---|
| SSD não reconhecido | Slot incompatível, instalação incorreta ou falha no dispositivo. |
| Velocidade abaixo do esperado | Geração ou pistas limitadas, temperatura ou configuração. |
| Temperatura elevada | Dissipação insuficiente ou carga intensa. |
| Travamentos | Firmware, erros de leitura ou falha no SSD. |
| Desempenho reduzido durante gravação | Cache esgotado, temperatura ou limite de desempenho. |
| Sistema não inicializa | Configuração de boot, sistema operacional ou incompatibilidade. |

**Procedimento básico:**

1. Verificar se o SSD aparece na BIOS/UEFI.
2. Conferir se o slot suporta NVMe.
3. Verificar a instalação física do SSD.
4. Consultar a geração PCIe e a quantidade de pistas.
5. Monitorar a temperatura.
6. Consultar os dados SMART.
7. Utilizar ferramentas de diagnóstico do fabricante.

**Atenção:** se houver suspeita de falha no SSD, priorize o backup dos dados antes de executar testes intensos.
