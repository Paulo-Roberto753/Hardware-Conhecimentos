## 02. Arquitetura: como um SSD NVMe funciona?

Um SSD NVMe possui componentes internos semelhantes aos de um SSD SATA, mas utiliza uma interface e um protocolo diferentes.

[storedbits.com](https://storedbits.com)

| Componente | Função |
|---|---|
| Memória NAND | Armazena os dados permanentemente. |
| Controladora | Gerencia as operações internas do SSD. |
| DRAM Cache | Auxilia no gerenciamento dos dados, quando presente. |
| Firmware | Controla o funcionamento interno do dispositivo. |
| Interface PCIe | Realiza a comunicação com o computador. |
| Protocolo NVMe | Gerencia os comandos de leitura e gravação. |

**Exemplo prático:**

Quando você abre um programa instalado no SSD NVMe:

1. O sistema operacional solicita os dados.
2. O protocolo NVMe organiza e envia os comandos.
3. A controladora localiza as informações na memória NAND.
4. Os dados são transferidos pelo PCIe.
5. O processador recebe as informações para continuar a execução.
