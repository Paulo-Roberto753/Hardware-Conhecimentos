## 16. Resumo: o que você precisa memorizar?

| Termo | Significado |
|---|---|
| NVMe | Protocolo de comunicação para armazenamento. |
| PCIe | Interface de comunicação. |
| PCIe 3.0/4.0/5.0 | Gerações da interface. |
| Lane | Pista de comunicação. |
| x2 | Duas pistas PCIe. |
| x4 | Quatro pistas PCIe. |
| M.2 | Formato físico de conexão. |
| 2280 | 22 mm × 80 mm. |
| M-Key | Tipo de chave física comum em SSDs NVMe. |
| Thermal Throttling | Redução de desempenho por temperatura. |
| AHCI | Protocolo tradicional utilizado com SATA. |
| DRAM Cache | Memória temporária auxiliar. |
