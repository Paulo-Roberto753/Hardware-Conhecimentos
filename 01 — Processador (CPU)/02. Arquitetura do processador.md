## 2. Arquitetura do processador

Arquitetura é a maneira como o processador é projetado e organizado para executar instruções.

Existem dois conceitos importantes:

**ISA (Instruction Set Architecture):** conjunto de instruções que o processador entende e executa.

**Microarquitetura:** implementação física e lógica utilizada para executar essas instruções.

### Principais arquiteturas e famílias:

| Arquitetura | Fabricante |
|---|---|
| x86 | Intel / AMD |
| x86-64 (AMD64) | Intel / AMD |
| ARM | ARM e fabricantes licenciados |

### Exemplos de famílias de microarquitetura:

- Intel: Skylake, Alder Lake, Raptor Lake.
- AMD: Zen, Zen 2, Zen 3, Zen 4, Zen 5.

**Para memorizar:** arquitetura define como o processador trabalha e como ele executa instruções. A microarquitetura representa o projeto interno que implementa esse funcionamento.
