## 9. Gerações e nomenclaturas

As gerações identificam famílias e períodos de lançamento dos processadores.

### Intel Core

Exemplos de nomenclatura tradicional:

**i7-12700K**

| Identificação | Significado |
|---|---|
| i7 | Linha / nível |
| 12 | Geração |
| 700 | Modelo |
| K | Sufixo |

**Interpretação:** Intel Core i7, 12ª geração, modelo 700, multiplicador desbloqueado.

### Sufixos Intel mais conhecidos:

| Sufixo | Significado |
|---|---|
| K | Desbloqueado para overclock |
| F | Sem gráficos integrados |
| KF | Desbloqueado e sem gráficos integrados |
| T | Perfil de menor consumo |
| H | Alto desempenho em notebooks |
| HX | Alto desempenho em notebooks, classe superior |
| U | Foco em eficiência energética |

### AMD Ryzen

Exemplo:

**Ryzen 5 5600X**

| Identificação | Significado |
|---|---|
| 5 | Categoria |
| 5 | Família 5000 |
| 600 | Modelo |
| X | Sufixo |

**Interpretação:** Ryzen 5, família 5000, modelo 5600X.

### Sufixos AMD conhecidos:

| Sufixo | Significado |
|---|---|
| X | Modelo com perfil de desempenho elevado |
| G | Modelo com gráficos integrados |
| X3D | Tecnologia 3D V-Cache |
| U | Foco em eficiência para notebooks |
| H | Alto desempenho para notebooks |
| HS | Alto desempenho com foco em eficiência |
| HX | Categoria de alto desempenho para notebooks |

**Importante:** as regras de nomenclatura variam entre famílias e gerações. Não interprete todos os números apenas pela posição. Consulte sempre a ficha técnica oficial.

### Como identificar a geração?

| Fabricante | Exemplo | Família |
|---|---|---|
| Intel | i5-10400 | 10ª geração |
| Intel | i5-12400 | 12ª geração |
| Intel | i5-14400 | 14ª geração |
| AMD | Ryzen 5 3600 | Série 3000 |
| AMD | Ryzen 5 5600 | Série 5000 |
| AMD | Ryzen 5 7600 | Série 7000 |
| AMD | Ryzen 5 9600X | Série 9000 |

**Atenção:** a numeração comercial não representa necessariamente a microarquitetura. Consulte o código de arquitetura e as especificações do fabricante.
