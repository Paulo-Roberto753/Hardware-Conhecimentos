## 17. Exemplo prático de interpretação

Vamos utilizar um processador conhecido:

### AMD Ryzen 5 5600X

| Especificação | Característica |
|---|---|
| Fabricante | AMD |
| Família | Ryzen 5000 |
| Arquitetura | Zen 3 |
| Núcleos | 6 |
| Threads | 12 |
| Clock base | 3,7 GHz |
| Boost máximo | Até 4,6 GHz |
| Cache L3 | 32 MB |
| Socket | AM4 |
| Litografia | 7 nm |
| TDP | 65 W |
| Gráfico integrado | Não |

*Exemplo de ficha técnica. Consulte o fabricante para condições e especificações completas.*

### O que você precisa concluir dessa ficha?

- É um processador de seis núcleos e doze threads.
- Utiliza arquitetura Zen 3.
- É compatível com plataformas AM4 que ofereçam suporte ao modelo.
- Não possui vídeo integrado.
- Precisa de solução gráfica independente para fornecer imagem.
- Sua refrigeração deve ser dimensionada considerando as características térmicas do modelo.
