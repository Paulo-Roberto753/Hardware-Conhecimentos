## 18. Revisão: o que você precisa saber de cabeça

| Termo | Significado |
|---|---|
| CPU | Unidade central de processamento |
| Core | Núcleo físico |
| Thread | Fluxo de execução |
| GHz | Frequência |
| Cache | Memória rápida do processador |
| ISA | Conjunto de instruções |
| Socket | Encaixe da CPU |
| TDP | Referência de projeto térmico |
| TjMax | Temperatura máxima de junção |
| Throttling | Redução de desempenho por limitação térmica |
| Overclock | Aumento manual da frequência |
| BIOS/UEFI | Firmware de inicialização |
| RMA | Autorização de retorno para atendimento |
