## 11. Temperaturas dos componentes

A temperatura é um dos indicadores utilizados para avaliar o funcionamento do sistema de refrigeração.

Cada componente possui limites de operação definidos pelo fabricante.

### Processador (CPU)

A temperatura varia conforme:

- Modelo;
- Consumo;
- Frequência;
- Tensão;
- Tipo de cooler;
- Temperatura ambiente;
- Carga de trabalho.

### Placa de vídeo (GPU)

As placas de vídeo podem apresentar diferentes leituras de temperatura:

- GPU Temperature: temperatura principal do chip;
- Hot Spot: região mais quente medida ou estimada no chip;
- Memory Junction: temperatura das memórias, quando disponibilizada.

### SSD NVMe

O SSD também produz calor durante operações intensas.

Temperaturas elevadas podem provocar redução de desempenho por proteção térmica.

### Observação sobre temperaturas

Não existe uma temperatura universal ideal para todos os componentes.

É necessário comparar as leituras com os limites e recomendações específicos de cada modelo.

**Exemplo:** dois processadores diferentes podem trabalhar normalmente em temperaturas distintas, dependendo da arquitetura e dos limites térmicos definidos pelo fabricante.
